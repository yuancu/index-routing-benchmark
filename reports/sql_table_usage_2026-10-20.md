## Catalog 对齐问题

另外发现 143 条 SQL 的表引用不能与当前 catalog 按原始名称（忽略大小写）完全对齐：Spider 1 条、BIRD 142 条，全部位于 train。这些 SQL 仍按自身引用的表计入上述统计。

存在表缺失及名称表示不一致的情况，例如 BIRD SQL 引用 `Order Details` 而 catalog 存为 `OrderDetails`。这里没有猜测或自动改名。表级数据转换前需要审查，不应将这些样本当作负例或默默删除。

JSON 保存了全部分布、schema 对齐异常、alias 警告和输入 SHA-256。普通样本的作用域表集合与 AST 表节点去除 CTE 名后的集合交叉检查结果一致。
